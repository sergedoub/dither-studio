# Changelog

## 1.0.0 — first public source release

- Standalone macOS Apple Silicon and browser editors with 41 independent algorithm choices.
- Mono, tonal, indexed, and RGB rendering; palette tools and image adjustments.
- PNG, grayscale mask, separated ink layers, batch ZIP, and JSON preset export.
- MIT license, contribution/security guidance, reproducible build instructions, CI, and allowlisted desktop packaging.
- Optional experimental Supabase adapter; live authenticated cloud verification remains outstanding.

Desktop binaries are unsigned and not notarized. See docs/limitations.md for algorithm approximations, memory limits, and unsupported workflows.
