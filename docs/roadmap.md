# Roadmap

The maintained baseline is a local-first dithering editor for browsers and macOS Apple Silicon.

## Known follow-up work

- Verify optional Supabase authentication, save/reload, and cross-user isolation in a dedicated test environment.
- Improve cloud account lifecycle: password recovery, user-facing deletion, and pagination beyond the latest 100 saves.
- Add more algorithm reference fixtures and browser compatibility coverage.

## Ideas, not commitments

- A documented programmatic image-processing API or CLI.
- Signed/notarized desktop releases.
- Windows, Linux, and Intel Mac packaging after testing.
- More efficient large batches and richer preset sharing.

The project does not promise a release schedule or support SLA. Discuss substantial changes in an issue before implementing them.
