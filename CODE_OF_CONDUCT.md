# Community code of conduct

Be respectful, constructive, and welcoming across experience levels and backgrounds. Critique ideas and code rather than attacking people. Respect privacy and credit others' work.

Harassment, discrimination, threats, sexualized conduct, deliberate disruption, and publishing private information without consent are unacceptable. These expectations apply to issues, pull requests, discussions, and project-related interactions.

Report concerns privately to the maintainer, @sergedoub, using the [private reporting form](https://github.com/sergedoub/dither-studio/security/advisories/new). For a conduct report, begin the title with "Conduct concern"; this channel avoids exposing private details in a public issue. Include only relevant evidence. Reports will be handled discreetly; confidentiality cannot be guaranteed where disclosure is necessary to address harm. There is no guaranteed response time.

The maintainer may request a correction, remove content, close a discussion, or temporarily or permanently restrict participation according to severity and repetition. Affected participants may ask for reconsideration through the same contact. Enforcement should be proportionate and consistent.
